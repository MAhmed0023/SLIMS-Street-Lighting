SLIMS — server requirements

Street Lighting Store, Issuance & Installation Management System: a web portal and API, a SQL Server database, a folder of geo-tagged installation photographs, and the SLIMS Field Android app used by Lighting Officers at the pole. Two virtual machines are requested.

Cores12vCPU

OS: Windows Server 2022 Standard ×64 (2019 acceptable). SQL Server Standard is requested — the free Express edition uses only about 1.4 GB of memory and four cores however large the VM is, so this specification pays off only on Standard. The 200 GB holds the database, its transaction log and local backups for many years — the database grows by roughly 1 GB per 100,000 items.

What fills the web server's 500 GB

Each installation stores a BEFORE and an AFTER photograph (1920×1080 JPEG) plus the server's stamped copy of each — about 2.5 MB per installation. Nothing else in the system grows.

Also needed from PITB

  • A web address and its security certificate — for example streetlight.pera.gop.pk, with an SSL certificate that PITB keeps renewed. The officers' app is downloaded from SLIMS itself, not from an app store, so this address is how phones install and update it; the browser also refuses to give an officer's location on an unsecured address.
  • Backups — the database and the photographs copied every night and kept for 30 days, plus a full copy of both servers once a week. One restore is tested every three months, so we know the backups work.
  • Three kinds of login — one administrator login per server for installing and updating, one account the application runs under, and one database login that can reach only the SLIMS database.

Why the public addresses are needed

Lighting Officers work in the field, so the web server has to be reachable over the internet: two public addresses, a DNS record and an SSL certificate. No VPN is required on the phones — the Android app connects straight to the published address over HTTPS.
